Import / Export databázy & Záloha
Hlavná databáza pre GitHub JSON
Exportuje kompletnú históriu všetkých dvojhier, štvorhier a hráčov pod presným názvom databaza.json.
Nahraj tento súbor na GitHub do rovnakého priečinka vedľa index.html, aby sa nové výsledky automaticky načítali všetkým.
Archívna lokálna záloha JSON
Uloží kompletnú kópiu databázy do PC s aktuálnym dátumom v názve súboru.
Ideálne na priebežné zálohovanie pred väčšími úpravami.
Obnova zo súboru JSON Import JSON
Načíta uložený súbor .json a okamžite prepočíta tabuľku pre aktuálnu časovú lehotu.
Pozor: Prepíše aktuálne dáta uložené v pamäti prehliadača.
Manuálny GitHub Sync Remote JSON
Okamžite stiahne oficiálny súbor databaza.json zo servera a prepíše lokálne úpravy.
Rovnakú funkciu má aj veľké zelené tlačidlo na karte Tabuľka.
Export rebríčka pre Excel CSV
Vygeneruje aktuálnu tabuľku pre zvolenú časovú lehotu vo formáte .csv (UTF-8 s BOM).
Slovenská diakritika sa v MS Excel zobrazí správne.
